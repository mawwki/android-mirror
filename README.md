# Android Mirror

Скринмирроинг Android-устройства на десктоп: Rust + egui-клиент, работающий напрямую
по протоколу [scrcpy](https://github.com/Genymobile/scrcpy) (сервер-джарник кладётся на устройство,
видео — H.264 через `openh264`, декодирование и рендер локально).

## Что умеет

- **Минимальный безрамочный режим** — окно-«стекло» поверх всего + трей (`tray-icon`)
- **Звук** — захват аудио с устройства (raw PCM → `rodio`)
- **UHID-клавиатура** — ввод с физической раскладкой ПК
- **Управление** — тапы, свайпы, колёсико, клавиши (control-протокол scrcpy)
- **Виртуальный дисплей** (scrcpy 3.x) — отдельный 1920×1080, экран телефона можно гасить
- Автоподключение при запуске, автоопределение adb и устройств

## Сборка

```bash
cargo run --release
```

Нужен только Rust; adb находится автоматически (или укажите путь в настройках приложения).
Сервер `scrcpy-server.jar` лежит в `assets/` и пушится на устройство сам.

## Структура

```
src/
  main.rs        — app-стейт, настройки, подключение
  adb.rs         — adb: устройства, пуш сервера, параметры
  connection.rs  — сокеты scrcpy, видео/аудио-потоки
  control.rs     — control-протокол (инжекты тапов/клавиш)
  keyboard.rs    — UHID-клавиатура
  md3.rs         — рисование UI в egui
  icons.rs       — Material Symbols (шрифт в assets/)
refs/            — Java-исходники scrcpy как справка по протоколу
```
